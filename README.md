# 节律光谱 · Rhythm Spectrum

把 24 种音乐流派放进一个节拍刻度盘：半径表示 BPM 区间、角度表示起源年代、颜色表示能量；支持 BPM 窗口筛选、流派散点切换与本地合成的节拍试听。

## 交互
- 拖动「最低 / 最高 BPM」滑块，筛选落在节拍窗口内的流派；
- 点击刻度盘扇区或散点切换流派；
- 点击「试听节拍」用 Web Audio 播放该流派的基准节拍（本地合成，需用户点击启动）。

## 数据说明
BPM 区间与能量（0–100）为常见编曲参考的简化值，非官方统计。

## 运行
```bash
npm install
npm run dev
npm run build
```
